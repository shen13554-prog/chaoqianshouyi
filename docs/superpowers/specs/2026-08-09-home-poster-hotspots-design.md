# 首页海报热点阅读体验设计规格

## 目标

在不替换、不裁切、不修改现有 `public/images/intro/intro_scroll_poster.webp` 的前提下，为首页文化介绍长海报增加七处悬停阅读热点。用户把鼠标移入海报左右文字区域时，可在原区域附近阅读经过精简转录的放大信息卡；移开热点与信息卡后自动隐藏。

## 修改范围

- 仅修改首页 `Home` 相关结构、数据和对应样式。
- 保留 Header、Footer、路由、其他页面和海报下方介绍文字。
- 不引入第三方组件或动画库。
- 不导入用户另行上传的 `潮嵌守艺1.jpg`。

## 交互结构

海报容器继续保持当前 `860px` 桌面展示宽度和完整纵横比，并改为热点定位上下文。七个热点使用相对海报宽高的百分比坐标覆盖原文字区域：

| 位置 | 热点 | 对应原区域 |
| --- | --- | --- |
| 左侧 | 嵌瓷介绍 | 海报左上“嵌瓷介绍” |
| 左侧 | 工艺介绍 | 海报左中“工艺介绍” |
| 左侧 | 核心特点 | 海报左中下“核心特点介绍” |
| 左侧 | 地区分布 | 海报左下“地区分布” |
| 右侧 | 标志建筑 | 海报右上“标志建筑” |
| 右侧 | 材料制作流程 | 海报右侧材料文字区 |
| 右侧 | 工艺步骤 | 海报最右侧步骤图示区 |

热点默认不覆盖原海报视觉，仅保留透明的可感知区域。鼠标进入时：

1. 当前热点显示低透明淡金轮廓。
2. 米白色信息卡向海报内侧展开，避开浏览器边缘。
3. 热点与信息卡之间显示一条砖红色细线及端点。
4. 信息卡以约 `180ms` 的透明度与轻微缩放过渡出现。
5. 鼠标可从热点移动到信息卡；离开二者后信息卡自动隐藏。

同一时间只显示当前悬停热点的信息卡，不改变页面滚动位置。

## 信息卡内容

内容只采用现有海报信息的精简转录，不增加未经确认的历史断言：

- **嵌瓷介绍：** 说明嵌瓷又称聚饶、粘瓷、扣饶，以彩釉瓷片剪裁镶嵌人物、花卉和飞禽走兽，多用于屋顶、墙壁等建筑装饰。
- **工艺介绍：** 概括塑胚胎、剪取瓷片、镶嵌瓷片和综合调整四个环节。
- **核心特点：** 展示色彩绚丽、质地坚固、立体感强和变废为宝四项特征。
- **地区分布：** 概括潮汕、闽南、台湾、海南等文化区域及其地方风格。
- **标志建筑：** 列出安济王庙、广济楼天后宫、观音庙和从熙公祠。
- **材料制作流程：** 概括贝壳灰、石灰、细沙、稻草、红糖浆和草根粗灰等材料的处理与配制。
- **工艺步骤：** 概括烧制、浸泡、加入、过滤、搅拌和调和等海报所示顺序。

## 视觉规则

- 信息卡背景使用低透明米白色，与现有 `--paper` 体系一致。
- 标题和连接线使用低饱和砖红色 `--vermilion`。
- 边框与端点使用 `--gold-soft` 和 `--gold`。
- 字体继承当前宋体/衬线字体体系。
- 信息卡提供轻微阴影和清晰文字层级，不改变海报原始像素。

## 组件与数据

- 首页内部新增 `posterHotspots` 数据数组，集中保存 `id`、标题、摘要、要点、左右方向及百分比坐标。
- 新增首页专用 `PosterHotspot` 组件，负责热点、连接线和信息卡的单一展示逻辑。
- 组件使用 `onMouseEnter`、`onMouseLeave` 和首页 `activeHotspot` 状态控制显示，不引入全局状态。
- 数据和组件仅供首页使用，不改变公共组件接口。

## 验证标准

1. 海报仍使用原有 WebP 文件并完整显示。
2. 七处热点均与对应文字区域对齐。
3. 每处热点悬停后显示正确标题和精简内容。
4. 信息卡与热点之间存在砖红细线，卡片不会改变文档布局。
5. 鼠标移开后信息卡自动隐藏。
6. 首页其他模块及其他页面不受影响。
7. `npm run build` 成功。
