# 「建筑再生」嵌瓷元素提取设计

## 目标

增强 `/modern` 案例 01「建筑再生」现有的“嵌瓷元素提取”模块，将色彩、纹样和拼接结构从简单文字列表升级为三个独立展陈单元。

## 范围

- 保留现有页面模块顺序，不新增重复的“嵌瓷元素提取”模块。
- 保留三案例状态切换、自动滚动和详情四段结构。
- 仅为案例 01 增加专用提取数据与条件展示。
- 案例 02、03 继续使用当前文字列表与单个占位框。
- 不新增图片素材或外部资源。

## 数据设计

为 `modernCases.js` 中 `architecture` 案例增加 `extractions` 数组，每项包含：

- `id`：稳定标识。
- `number`：展陈编号。
- `title`：色彩提取、纹样提取或拼接结构提取。
- `description`：对应的分析说明。

三项内容：

1. 色彩提取：提炼低饱和朱红、釉绿与金色关系，保留传统建筑装饰的节奏和层次。
2. 纹样提取：从龙凤、花鸟及卷草中提取轮廓与连续构图，形成可复用的现代图形语言。
3. 拼接结构提取：分析瓷片的方向排列、碎片层叠和高低起伏，呈现嵌瓷特有的立体秩序。

## 组件兼容

`ModernCaseDetail.jsx` 在现有“嵌瓷元素提取”文章内部进行条件渲染：

- 存在 `extractions` 时，渲染三个独立展陈单元，每项包含编号、标题、说明和图片占位区域。
- 不存在 `extractions` 时，继续渲染原有 `elements` 列表和“纹样提取预览”占位框。

不改变文章在页面中的位置，也不影响其他详情模块。

## 视觉设计

三个单元横向三列排列。每项采用米白背景、深墨文字、朱红编号和朱红细线分隔；占位区域沿用现有深色展陈风格。仅新增 `.modern-extraction-*` 局部样式，不调整网站整体 CSS 变量或其他模块样式。

## 验证标准

- 案例 01 显示色彩提取、纹样提取、拼接结构提取三个单元。
- 每个单元包含独立说明和图片占位区域。
- 案例 02、03 仍显示原有列表和单占位框。
- 三案例切换与自动滚动正常。
- 1280×720 下无遮挡或横向溢出。
- 全量测试和 `npm run build` 通过。
