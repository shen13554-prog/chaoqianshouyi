# 全站山水背景设计规格

## 目标

使用用户提供的山水 PNG 作为全站唯一装饰背景，在不改变页面布局、内容结构和交互行为的前提下，为所有路由提供统一的东方山水视觉。

## 实现范围

- 将图片保存为项目内的全局背景资源。
- 使用 `body::before` 创建固定于视口的背景层，不增加 React 页面节点。
- 背景层固定在页面底部，水平居中，保持图片原始比例。
- 背景层透明度设为 `0.14`，位于要求的 `0.1–0.18` 范围内。
- 使用 CSS 遮罩令画面从上方透明、向底部逐渐显现。
- 设置 `pointer-events: none`，确保背景不拦截按钮、链接或其他交互。
- 正文内容维持原有层级并显示在背景之上。

## 视觉规则

- `body` 保留现有米白色作为基础底色。
- 移除 `body` 当前的装饰性渐变纹理，确保山水 PNG 是唯一图像背景。
- 桌面端使用覆盖视口的比例适配，并以底部山水主体为视觉锚点。
- 手机端只调整背景图尺寸和定位规则，不改动现有页面布局或组件响应式行为。

## 兼容与交互

- 同一背景规则作用于 `App` 下的全部页面和路由。
- 背景层使用负面交互隔离，不参与布局、不产生滚动条、不影响文字选中。
- 同时提供标准 `mask-image` 与 WebKit 前缀，覆盖常见 Chromium、Safari 和移动浏览器。

## 验证标准

1. 所有页面使用同一张山水背景，且固定在视口底部。
2. 页面滚动时背景保持固定，顶部自然渐隐。
3. 文字可读，按钮和链接可正常点击。
4. 桌面与手机视口下背景保持比例并覆盖可视区域。
5. 页面布局尺寸和组件位置不发生改变。
6. `npm run build` 成功完成。
