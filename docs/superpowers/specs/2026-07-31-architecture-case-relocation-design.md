# 建筑再生案例迁移设计

## 目标

将“建筑再生”从 `/modern` 潮艺新生页面迁移到现有 `/building` 建筑页面，使现代页面只承担“日常新生”和“艺术跨界”两个现代转译案例，建筑内容回归建筑主题页面。

## 路由与入口

- 保留现有 `/modern` 和 `/building` 路由，不新增详情路由。
- `/modern` 仅显示“日常新生”和“艺术跨界”两个案例入口，默认选中“日常新生”。
- 顶部导航“建筑案例”和首页“建筑艺术”继续跳转 `/building`。
- `/building` 本身作为“建筑再生”详情页，用户点击现有建筑入口后直接进入详情内容。

## 数据设计

- 将当前“建筑再生”对象保留为 `architectureCase` 独立导出。
- `modernCases` 数组仅保留“日常新生”和“艺术跨界”。
- 不删除“建筑再生”的任何字段、图片路径或分析文字。
- “现代设计应用”和“设计说明”数据继续保留在 `architectureCase`，但不在 `/building` 页面展示。

## 页面结构

### `/modern`

- 保留现有介绍区、案例选择器、同页切换和自动滚动。
- 案例选择器只渲染“日常新生”和“艺术跨界”。
- 详情继续使用现有 `ModernCaseDetail` 完整展示传统来源、元素提取、现代应用和设计说明。

### `/building`

- 移除当前 `BasicPage` 基础图片展示。
- 使用 `architectureCase` 渲染“建筑再生”详情。
- 页面只显示：
  1. 建筑再生标题与简介。
  2. 传统来源说明。
  3. 安济王庙、广济楼天后宫、观音庙、从熙公祠四张建筑图片。
  4. 色彩提取、纹样提取、拼接结构提取三个展陈分析单元。
- 不显示“现代设计应用”和“设计说明”区块。

## 组件兼容

为 `ModernCaseDetail` 增加 `showModernTranslation` 布尔属性，默认值为 `true`：

- `/modern` 不传该属性，保持案例 02、03 当前完整详情结构。
- `/building` 传入 `showModernTranslation={false}`，仅展示标题、传统来源和嵌瓷元素提取。
- 现有图片画廊、元素提取展陈、视觉样式和无障碍名称全部复用，不复制组件代码。

## 视觉要求

- 不修改全局视觉变量或页面整体样式。
- `/building` 复用当前米白宣纸背景、深墨文字、朱红细线、金色分隔和宋体展陈风格。
- 不新增图片、不修改图片路径、不调整其他页面样式。

## 测试与验收

- `/modern` 只存在“日常新生”和“艺术跨界”两个案例按钮。
- `/modern` 默认显示“日常新生”，点击“艺术跨界”后详情切换并自动滚动。
- `/building` 显示建筑再生标题、传统来源、四张建筑图片和三个元素提取单元。
- `/building` 不显示现代设计应用和设计说明区块。
- `/modern` 与 `/building` 均无横向溢出或控制台应用错误。
- 全量测试和 `npm run build` 通过。
