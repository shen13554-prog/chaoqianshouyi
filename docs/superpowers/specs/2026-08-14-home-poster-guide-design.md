# 首页海报轻量交互引导设计

## 目标

为首页文化介绍海报增加一次性轻量提示，引导用户发现已有热点交互，同时不遮挡海报，不改变热点、侧边资料卡或首页其他模块。

## 交互规则

- 提示文案固定为“移至海报细节 · 探索嵌瓷信息”。
- 提示位于海报外正中间上方。
- 海报首次进入视口且本地未记录已查看时显示提示。
- 提示展示约 3.5 秒后淡出。
- 用户首次 hover 任意热点时立即隐藏提示。
- 提示实际显示后，通过 `localStorage` 记录已查看状态，后续访问不重复显示。

## 实现范围

- 在首页管理引导可见状态、视口监听、计时器和本地记录。
- 现有热点组件只增加一个可选的 hover 通知回调，不改变激活与资料卡行为。
- 使用 CSS 绘制小型鼠标图标，并沿用米白、砖红、浅金视觉。
- 不增加第三方依赖，不修改其他页面。

## 验证

- 首页测试覆盖首次进入视口显示、3.5 秒后隐藏、热点 hover 立即隐藏及已查看时不重复显示。
- 运行首页测试与 `npm run build`。
