# “守艺传承”传承谱系页面设计规格

## 目标

将 `/inheritors` 从规则四宫格升级为非遗数字档案式交互页面。保留现有 Header、Footer、路由、人物插画和全站视觉变量，不修改其他页面。

## 页面结构

1. 页面标题：“守艺传承”。
2. 副标题：“一条屋脊，连接数代匠人的坚守与创新”。
3. 中部使用 SVG 绘制参考潮汕燕尾脊形态的金色曲线。
4. 陈伟钦、卢芝高、许少鹏、许少雄以圆形人物节点沿路径错落排布。
5. 下方详情区使用左图右文布局，显示姓名及身份、传承年代、主要技艺、代表作品、传承贡献五项字段。

## 交互

- 默认选中陈伟钦。
- 点击人物节点切换当前人物与详情。
- 节点使用原生按钮，支持 Tab 聚焦以及 Enter、空格激活。
- 当前节点通过朱红印记、金色外环和轻微阴影高亮。
- 详情切换只使用短暂透明度与位移过渡，不使用复杂动画。

## 数据约束

- 四位人物仅使用现有姓名和站内插画。
- 五项人物资料统一使用“待补充”，不生成具体身份、年代、技艺、作品或贡献事实。
- 人物数据独立存放，后续替换真实资料时不需要修改组件结构。
- 第二位人物名称按本次需求使用“卢芝高”，图片继续使用现有 `lu_yigao.png`。

## 视觉

- 沿用米白宣纸背景、深墨文字、朱红强调、金色细线。
- 路径周围使用少量 CSS 瓷片形状与低透明度纹样，不新增图片素材。
- 页面保持最大内容宽度 1280px，仅制作 PC 端。

## 验收标准

- 四个节点均显示且不形成规则宫格。
- 默认节点正确，点击和键盘操作可切换详情。
- 五项占位字段完整显示。
- 四张现有人物插画均正常加载。
- `/inheritors` 之外的页面、路由与样式不受影响。
- 相关测试与 `npm run build` 通过。
