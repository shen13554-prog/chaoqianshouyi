# 「建筑再生」案例内容完善设计

## 目标

在不改变 `/modern` 页面结构、三个案例切换方式和既有视觉系统的前提下，完善案例 01「建筑再生」的内容表达，使其清晰呈现传统建筑来源、嵌瓷元素提取、现代设计应用和数字化转译理念。

## 实施范围

- 仅更新 `src/data/modernCases.js` 中 `architecture` 案例的数据。
- 保留 `Modern.jsx`、案例选择组件、详情组件和现有 CSS。
- 继续使用当前站内占位框，不增加外部图片或新素材。
- 不调整案例 02「日常新生」和案例 03「艺术跨界」。

## 案例内容

### 传统来源

介绍潮州嵌瓷在祠堂、庙宇和传统民居中的应用，重点说明屋脊、山墙等建筑部位，以及龙凤、花鸟等装饰题材。

### 嵌瓷元素提取

- 色彩：提取低饱和朱红、釉绿与金色关系。
- 纹样：提取龙凤、花鸟及卷草轮廓。
- 瓷片拼接结构：保留碎片层叠、方向排列与高低起伏。

### 现代设计应用

说明传统色彩、纹样和拼接秩序如何转化为空间界面、导视系统与公共艺术语言。

### 设计说明

突出传统文化的数字化转译，以及非遗元素在现代设计中的延续和应用；强调提炼文化结构，而非简单复制传统装饰。

## 交互与视觉

案例仍通过现有 React 状态进行同页切换。点击「建筑再生」后沿用当前自动滚动和沉浸式详情展示。米白背景、宋体、朱红强调、金色细线及占位框样式均保持不变。

## 验证标准

- 案例 01 显示四段更新后的内容。
- 元素提取明确包含色彩、纹样和瓷片拼接结构。
- 三个案例按钮仍可切换，并保持自动滚动。
- 全量测试和 `npm run build` 通过。
- 浏览器中 `/modern` 无控制台错误或布局回归。
