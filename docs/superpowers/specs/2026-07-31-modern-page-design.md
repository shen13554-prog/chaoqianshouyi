# 潮艺新生页面设计

## 目标

在现有 `/modern` 路由内建立同页沉浸式案例体验，展示嵌瓷从传统来源到现代设计应用的转化。

## 页面结构

页面由标题引导、三个案例入口和一个详情区域构成。三个入口依次为“01 建筑再生”“02 日常新生”“03 艺术跨界”。点击入口后更新当前案例，并平滑滚动到详情区域。

详情区域顶部显示当前案例标题，正文按“传统来源、嵌瓷元素提取、现代设计应用、设计说明”纵向排列。前三部分使用不包含外部图片的展陈占位区域，第四部分显示设计理念文字。

## 交互与视觉

使用 React 本地状态保存当前案例，不新增路由。选中入口使用朱红强调，分隔与占位框使用金色细线；背景、字体与留白继续复用现有米白宣纸和宋体视觉系统。不添加复杂动画。

## 变更边界

仅修改 `src/pages/Modern.jsx` 和 `src/styles.css`，新增 Modern 页面专用数据、组件和测试。不修改其他页面、Header、Footer 或路由配置。
