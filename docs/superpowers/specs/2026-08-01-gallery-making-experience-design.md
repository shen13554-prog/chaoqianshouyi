# Gallery 三类嵌瓷制作体验优化设计

## 目标

在不改变 Gallery 页面整体布局、路由、Header、Footer 和作品数据结构的前提下，优化“三类嵌瓷制作体验”模块。制作步骤使用语义准确的站内工艺图片；没有对应图片的步骤仅展示文字；分类成品图只用于最后的完成步骤。

## 实施范围

- 仅调整 Gallery 页面制作体验模块的数据与局部交互样式。
- 保留现有分类切换、作品展示、图片预览及其他页面功能。
- 不生成图片，不调用外部图片，不增加占位图，不把成品图冒充过程图。

## 步骤与素材映射

### 半浮嵌

1. 选择瓷片：`/images/process/sorting.webp`
2. 拼接纹样：无精确过程图，仅展示文字
3. 嵌贴装饰：`/images/process/inlay.webp`
4. 完成作品：仅使用 `/images/works/half/` 中对应分类成品图

### 立体嵌

1. 绘制草图：`/images/process/sketch.webp`
2. 扎骨定形：`/images/process/frame.webp`
3. 灰浆塑形：`/images/process/plaster.webp`
4. 嵌入瓷片：`/images/process/inlay.webp`
5. 完成造型：仅使用 `/images/works/stereo/` 中对应分类成品图

### 平嵌

1. 分色选片：`/images/process/sorting.webp`
2. 剪修瓷片：`/images/process/trimming.webp`
3. 排列纹样：无精确过程图，仅展示文字
4. 完成装饰：仅使用 `/images/works/flat/` 中对应分类成品图

## 内容展示

每个步骤包含步骤序号、步骤标题和一段简短工艺说明。存在精确图片时展示图片；没有对应图片时保留稳定的文字展陈区域，不渲染图片容器、占位内容或虚构视觉。

## 交互与视觉

- 点击步骤后切换当前步骤内容。
- 当前步骤沿用朱红色强调与金色细线高亮。
- 图片内容切换时采用轻微淡入和约 `0.98` 到 `1` 的缩放，不引入第三方动画库。
- 切换到无图步骤时仅更新文字内容，不显示残留图片。
- 保持米白宣纸背景、宋体风格和现有中式展陈视觉。

## 验证标准

- 三个分类的步骤名称、顺序和说明完整。
- 所有过程图均与步骤语义匹配。
- 三类成品图只出现在各自最后一步，且目录匹配。
- “拼接纹样”和“排列纹样”不显示图片或占位图。
- 点击步骤能正确高亮和切换内容，图片执行轻微淡入放大。
- Gallery 既有布局和其他页面不受影响。
- Gallery 测试与 `npm run build` 均通过。
