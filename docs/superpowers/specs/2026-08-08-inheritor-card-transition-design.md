# 传承人物资料卡方向切换动画

## 目标

保留现有人物节点、资料内容、分页功能和资料卡布局，只为上一页与下一页切换增加具有明确方向感的过渡动画。

## 动画规则

- 总时长为 0.4 秒，旧资料卡与新资料卡同步交叉滑动。
- 点击“上一页”时，当前资料卡向右退出，新资料卡从左侧进入。
- 点击“下一页”时，当前资料卡向左退出，新资料卡从右侧进入。
- 人物节点直接点击继续使用现有资料卡切换方式，不改变其交互语义。
- 动画期间保持资料卡外层尺寸稳定，避免页面高度或周围布局跳动。

## 实现边界

- 在现有传承人物组件中记录分页方向与过渡阶段。
- 动画期间短暂保留旧人物资料，并与新人物资料在同一稳定容器内叠层显示。
- 动画结束后只保留当前人物资料，避免隐藏副本持续占用 DOM。
- 使用传承人物专属 CSS 类完成位移与透明度过渡，不修改全局视觉系统。
- 不修改 `src/data/inheritors.js` 的人物内容和顺序，不修改路由或其他页面。

## 验证

- 上一页与下一页的进入、退出方向分别正确。
- 动画持续 0.4 秒，切换后分页边界状态正确。
- 动画期间资料卡尺寸和页面布局稳定。
- 传承人物定向测试与 `npm run build` 通过。
