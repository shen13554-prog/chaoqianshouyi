# 传承人物资料卡分页按钮视觉优化

## 目标

在不改变资料卡结构、人物数据与分页逻辑的前提下，将“上一页”和“下一页”稳定放置在资料卡内容区左右下方，并与“潮嵌守艺”现有视觉系统保持一致。

## 方案

- 保留现有 `.inheritor-detail__pagination` 文档流结构，不使用绝对定位。
- 资料内容区使用纵向弹性布局，使分页导航自然贴近内容区底部，避免资料较长时发生遮挡。
- 分页导航继续使用 `justify-content: space-between`：上一页位于左下方，下一页位于右下方；已有空占位负责保持单按钮时的正确方向。
- 按钮采用宋体风格、低透明砖红色文字和金色细线，默认状态弱化。
- 悬停与键盘聚焦时文字加深，并通过伪元素将短线水平展开；动画控制在约 240ms。
- 保留现有资料卡切换淡入动画和所有分页状态逻辑。

## 修改范围

仅修改 `src/styles.css` 中传承人物资料卡内容区和分页按钮相关选择器。不修改 React 组件、人物数据、路由或其他页面。

## 验证

- 第一位人物仅显示右下角“下一页”。
- 中间人物显示左下角“上一页”和右下角“下一页”。
- 最后一位人物仅显示左下角“上一页”。
- 悬停时文字和短线反馈正常，按钮不遮挡资料。
- `npm run build` 成功。
