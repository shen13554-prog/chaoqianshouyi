# 首页 16:9 视频序章 Banner 设计规格

## 目标

在首页导航栏下方、现有 Hero 之前加入一个沉浸式 16:9 视频序章。桌面端画面高度约占首屏 76%，视频自动静音播放一次，结束后停留最后一帧 1.5 秒，再以固定约 2 秒的缓动滚动进入现有首页内容；用户也可以点击右上角“跳过序章”立即进入首页。

## 范围

- 只修改首页和新增首页视频 Banner 组件、对应样式与测试。
- 保留 Header、Footer、路由、现有 Hero、海报热点、探索模块和作品模块。
- 使用已有视频 `src/assets/video/chaoqian-intro.mp4`。
- 不添加第三方运行时依赖，不循环播放视频。
- 移动端适配仅覆盖视频 Banner 本身；不在本次任务中重构网站现有 `1180px` PC 布局体系。

## 组件结构

新增 `src/components/IntroVideoBanner.jsx`，职责保持单一：

1. 渲染视频、封面和“跳过序章”按钮。
2. 监听视频 `ended` 事件。
3. 管理结束后 1.5 秒等待、2 秒滚动和清理定时器/动画帧。
4. 在滚动开始时通知首页进入内容揭示状态。

`Home.jsx` 负责：

- 将 Banner 放在现有 Hero 之前。
- 使用 `ref` 标记 Hero 作为滚动目标。
- 使用 React state 为首页内容切换揭示状态。

## 视频与封面

- 视频通过模块导入引用 `../assets/video/chaoqian-intro.mp4`。
- 从视频首个可解码画面原样提取一张 JPEG，保存为 `src/assets/video/chaoqian-intro-poster.jpg`。
- 封面只来自该视频，不调用外部图片，不生成新画面。
- 提取使用本机浏览器的视频解码能力捕获首帧；输出保持视频原始宽高比。
- `<video>` 设置 `autoPlay`、`muted`、`playsInline` 和 `poster`，不设置 `loop`。
- 桌面端外层为沉浸式首屏展陈区域，视频画面高度目标为 `76vh`，处于要求的首屏 70%–80% 区间；画面宽度根据 16:9 比例计算并居中，超宽屏两侧以低饱和深墨棕承接。
- 容器使用 `aspect-ratio: 16 / 9`；视频宽高均为 `100%`，使用 `object-fit: contain`，不裁切主体。
- 视频播放结束后不重置 `currentTime`、不替换 `src`，浏览器自然保留最后一帧。

## 播放与滚动时序

### 自动进入

1. 视频播放结束触发 `onEnded`。
2. 保持最后一帧 1500ms。
3. 清除可能存在的旧定时器。
4. 启动一次 2000ms 自定义滚动。
5. 滚动目标为 Hero 顶部相对文档的位置。

### 跳过序章

1. 点击“跳过序章”。
2. 立即暂停视频。
3. 清除结束等待定时器。
4. 启动同一个 2000ms 自定义滚动。

### 防重复与清理

- 使用 ref 记录滚动是否已经启动，防止 `ended` 与跳过按钮重复触发。
- 组件卸载时清除 `setTimeout` 和 `requestAnimationFrame`。
- 自动播放被浏览器阻止时仍显示首帧封面与跳过按钮，用户可以正常进入首页内容。

## 2 秒滚动实现

不使用时长不可控的原生 `scrollIntoView({ behavior: "smooth" })`。组件使用 `requestAnimationFrame`：

- 记录起始滚动位置、目标位置和起始时间。
- 使用 `easeInOutCubic` 计算每一帧进度。
- 调用 `window.scrollTo(0, nextY)`。
- 进度达到 1 时停止，持续时间为 2000ms。

这样可以满足“约 2 秒缓慢进入首页”的明确时序要求，同时不引入动画框架。

## 内容淡入

- Banner 初始显示时，现有首页主体保持可访问，但需要淡入的视觉元素处于轻微下移与低透明度状态。
- 滚动开始时，Home 设置 `isContentRevealed = true`。
- Hero 标题区、首页链接/按钮和文化海报内容使用同一揭示状态，采用约 800ms 的透明度与位移过渡。
- 元素使用小幅 `translateY`，不改变布局占位，不影响热点交互。
- 不隐藏正文或图片的语义内容；JavaScript 不可用时页面仍按原结构展示。

## 视频与 Hero 的视觉连续

- 保留现有 Hero 建筑图片和文案，不替换素材。
- 视频 Banner 底部加入由透明到米白宣纸色的低强度渐隐层，使青龙建筑最后一帧自然过渡到网站背景。
- 2 秒滚动开始时同步揭示 Hero 图片与标题区，透明度和轻微位移逐步恢复。
- Banner 与 Hero 之间不插入新的内容模块，滚动终点直接对准 Hero，形成“影像序章 → 建筑主视觉”的连续叙事。

## “跳过序章”按钮视觉

- 固定在 Banner 内右上角，而不是视口全局固定。
- 使用半透明米白底、金色细边、砖红文字和宋体体系。
- 与视频边缘保留安全间距，悬停时只增强背景和边线，不添加复杂动画。
- 按钮层级高于视频，保留键盘焦点可见状态。

## 移动端处理

- Banner 宽度为 `100%`，视频画框始终保持 16:9；桌面端高度约为 `76vh`。
- 使用 `object-fit: contain`，不裁切任何视频主体。
- 在窄屏媒体查询中缩小按钮字号、内边距和外边距。
- 本次不移除全站现有 `min-width: 1180px`，避免影响其他页面；因此这是 Banner 局部适配，不等同于全站响应式重构。

## 测试

更新/新增首页测试，覆盖：

1. Banner 位于 Hero 之前。
2. 视频具有 `autoplay`、`muted`、`playsinline`、poster，且没有 `loop`。
3. `ended` 后先等待 1500ms，再启动滚动。
4. 自定义滚动持续到 2000ms 并到达 Hero 目标位置。
5. 点击“跳过序章”会暂停视频、取消等待并立即启动滚动。
6. 重复触发不会启动第二次滚动。
7. 首页内容在滚动开始时获得淡入状态。
8. 现有首页海报热点测试继续通过。
9. 完整测试和 `npm run build` 通过。
