# 建筑案例弹窗分页交互设计规格

## 目标

在保持建筑弹窗现有左图右文布局、关闭按钮位置、字体和配色不变的前提下，为四个建筑资料增加上一页/下一页切换与 0.4 秒双向退出/进入动画。

## 数据来源

继续使用 `src/data/modernCases.js` 中的 `architectureCase.sourceImages` 数组，不复制或重写建筑资料。数组顺序即分页顺序：

1. 安济王庙
2. 广济楼天后宫
3. 观音庙
4. 从熙公祠

每项继续提供 `id`、`src`、`name`、`type`、`location` 和 `meaning`。

## 状态与切换

分页逻辑封装在 `BuildingResearchGallery` 内：

- `activeId` 继续表示父组件当前选中的建筑。
- 组件根据 `activeId` 在 `images` 数组中计算当前索引。
- 新增分页动画状态，记录 `phase`（idle、exit、enter）和 `direction`（previous、next）。
- 点击分页按钮后先播放当前资料退出动画。
- 400ms 后调用现有 `onToggle(nextId)` 切换建筑，再播放新资料进入动画。
- 再经过 400ms 后回到 idle。
- 动画期间分页按钮禁用，避免快速连续点击产生索引竞态。
- 组件卸载或弹窗关闭时清除等待中的计时器。

## 分页规则

- 第一项只显示右下角“下一页”。
- 第二、第三项同时显示左下角“上一页”和右下角“下一页”。
- 第四项只显示左下角“上一页”。
- 不循环分页，不刷新页面。
- 分页后弹窗的可访问名称、图片、建筑类型、嵌瓷位置和文化寓意同步更新。

## 动画范围

弹窗遮罩、米白外框和右上角关闭按钮保持静止。仅左侧建筑图片和右侧资料内容参与动画：

- 下一页：旧内容向左退出，新内容从右进入。
- 上一页：旧内容向右退出，新内容从左进入。
- 每段动画时间为 400ms。
- 动画使用透明度与水平位移，不新增复杂动画库。

## 视觉规则

- 分页按钮定位在弹窗左下角和右下角。
- 按钮继承现有米白、砖红、金色细线和宋体体系。
- 默认状态弱化，悬停时文字和短线增强。
- 按钮不会改变现有两栏宽度、图片 contain 规则或关闭按钮位置。

## 修改范围

- 修改 `src/components/BuildingResearchGallery.jsx`。
- 修改 Building 相关 CSS。
- 更新 `src/pages/Building.test.jsx`。
- 不修改其他页面、路由、公共导航或建筑资料内容。

## 验证标准

1. 从任意建筑图片打开弹窗时资料匹配。
2. 第一项、中间项、最后一项按钮显示规则正确。
3. 下一页和上一页按指定方向执行 400ms 退出/进入动画。
4. 切换后图片和全部右侧资料同步更新。
5. 关闭按钮和遮罩关闭继续正常。
6. Building 测试通过。
7. 完整测试与 `npm run build` 通过。
